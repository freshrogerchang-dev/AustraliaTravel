## 一句話目標
提供 2027/6/16–6/29 六歲親子澳洲行程，華航台北→雪梨、布里斯本→台北，每日整合景點、餐廳、地圖與近期旅行閱讀。

## Phase 狀態
- S1 架構：既有靜態單頁，保留 HTML/CSS/JavaScript 與 GitHub Pages main 根目錄發布。
- S2 相容性：viewport、響應式樣式、大字切換已實作；新增 manifest.json／圖示支援加入主畫面，實際手機待驗。
- S3 考察：本次景點與 2025–2026 來源查核完成，2027 實際開放仍待出發前確認。
- S4 建置：六歲版內容與海岸手帳視覺完成；本次加入去回程班號與兩個六歲備選景點。
- S5 驗證：本次靜態與桌面瀏覽器限定檢查通過；iPhone／Android 實機、加入主畫面流程未驗證。

## 未決問題 / 風險
- CI51／CI54 起降時間、機型與營運星期取自第三方航班追蹤網站，彼此數字略有出入，非華航官方確認；國內線班號、住宿、門票及接送均未預訂。
- Dig IT 目前要求理解英語安全說明、包鞋、家長監督；六歲符合目前年齡門檻不代表一定適合個別孩子。
- 海事博物館有 2026 年工程公告；2027/6 船艦可登狀態須重查。
- HOTA 與 Vivid 的 2027 實際節目／路線待確認。
- Luna Park 身高分區、Queensland Museum／SparkLab 開放時間與適齡建議以官網查核日為準，出發前應再核對。
- 近兩年來源中部分為英文、短評或官方指南；頁面已誠實標示。
- 實際手機 Safari／Chrome、「加入主畫面」安裝流程、無障礙輔具與旅行當日現場狀態未驗證。
