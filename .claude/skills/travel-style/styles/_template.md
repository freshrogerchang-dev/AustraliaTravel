# 風格名稱（theme id：`xxx`）

> 新增風格時複製這份。四個核心段落（字型、插圖畫法、色票形狀、動態）都要寫到能直接實作的程度；寫不出「插圖畫法」就代表這還不是一個風格，只是一組配色。

## 一句話
這個風格像什麼實體物件？（例：舊旅遊海報、護照內頁、小孩的圖畫本）

## 適合
什麼旅程、什麼讀者（親子、大人紀念、印出來）。取材來源：哪些當地日常視覺文化（不是神聖或原住民族專屬的符號）。

## 字型
| 用途 | 字型 | Google Fonts 參數 | 字重 |
|---|---|---|---|
| 中文內文／標題 | | | 最多兩個字重 |
| 英數展示 | | | |

- 確認字型有繁體中文字（用 `curl 'https://fonts.googleapis.com/css2?family=名稱'` 看有沒有回傳 @font-face）。
- 字距、行高、標題字重的特別設定。

## 色票與形狀
```css
html[data-theme="xxx"] {
  --paper: ; --bg: ; --ink: ; --ink-2: ;
  --coral: ; --yellow: ; --water: ; --green: ;
  --coral-t: ; --yellow-t: ; --water-t: ; --green-t: ;
  --line: ; --r-xl: ; --r-lg: ; --r-md: ; --r-sm: ;
  --shadow: ;
  --font: ; --display: ;
}
```
插圖色票（illustrations.js PALETTES）：P、I、C、Y、W、G、sw（線寬）。

## 插圖畫法
- 描邊：有沒有、多粗、什麼色
- 填色：平塗／排線／色塊錯位／透明暈染／像素
- 紋理：用什麼靜態 pattern（不能用 filter）
- 插圖底色：和紙色的形狀會不會消失？
- 風格專屬的小道具（只在這個風格出現的插圖元素）
- 給一小段 SVG 範例

## 版面元件
選單列、章節標題、日期標籤、卡片、「必去」、待辦勾選框、按鈕各自怎麼變。

## 動態（只動 transform／opacity）
- 插圖待機動畫
- 換日動畫（`.pop` 換成哪個 keyframes）
- 勾選待辦的回饋（`.just`）
- 減少動態效果時的最終狀態

## 不要做
文化、版權、可讀性、效能上的地雷。

## 檢查點
截圖時要特別看的地方。
